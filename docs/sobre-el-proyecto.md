# Sobre el proyecto

Amani Psicología es una aplicación Android orientada a la gestión de consultas psicológicas, citas y seguimiento emocional. El README del repositorio la describe como un proyecto educativo desarrollado en el IES Enrique Tierno Galván.

## Colaborar

Las contribuciones se gestionan mediante pull requests e incidencias en el repositorio de GitHub. Existen plantillas de issue en `.github/ISSUE_TEMPLATE/` enfocadas en el módulo de chat entre psicólogo y paciente, aunque no se incluye un archivo `CONTRIBUTING.md` general.
