Conversation

data class Conversation(val id: String = "", val pacienteId: String = "", val pacienteNombre: String = "", val psicologoId: String = "", val psicologoNombre: String = "", val lastMessage: String = "", val lastMessageTime: Long = System.currentTimeMillis(), val estado: ConversationState = ConversationState.ACTIVA, val unreadCount: Int = 0)

Representa una conversación de chat entre un paciente y un psicólogo.

Agrupa los metadatos necesarios para mostrar la bandeja de conversaciones, incluyendo el último mensaje intercambiado, el estado de la conversación y el contador de mensajes no leídos.
