ListarPacientesByPsicologoViewModel

class ListarPacientesByPsicologoViewModel(authRepository: AuthRepository, citasRepository: CitasRepository)

ViewModel que lista los pacientes asignados a un psicólogo junto con sus citas.

Obtiene la lista de pacientes desde AuthRepository y cruza la información con la agenda del psicólogo desde CitasRepository para exponer un mapa de citas por paciente en citasPorPaciente.
