Screens

sealed class Screens

Clase sellada que define todas las rutas de navegación de la aplicación.

Cada objeto hijo representa una pantalla accesible a través del org.ies.tierno.applicationamani.presentation.navigation.navGraph.NavGraph. El uso de una clase sellada garantiza que las rutas se gestionan de forma segura en tiempo de compilación.
