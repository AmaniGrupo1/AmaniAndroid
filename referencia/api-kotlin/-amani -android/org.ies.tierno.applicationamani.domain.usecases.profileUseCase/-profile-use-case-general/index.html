ProfileUseCaseGeneral

class ProfileUseCaseGeneral(val repository: ProfileRepository)

Caso de uso genérico para la gestión de perfiles de psicólogos, pacientes y administradores.

Delega en el repositorio de perfiles las operaciones de consulta, actualización y subida de foto para los tres tipos de usuario.
