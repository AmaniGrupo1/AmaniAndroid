SituacionViewModel

class SituacionViewModel(useCase: SituacionUseCase, userSessionDataStore: UserSessionDataStore)

ViewModel que gestiona el CRUD de situaciones desde el panel de administración.

Permite listar, consultar por ID, crear, actualizar y eliminar situaciones mediante SituacionUseCase. Espera a que exista una sesión válida antes de cargar los datos.
