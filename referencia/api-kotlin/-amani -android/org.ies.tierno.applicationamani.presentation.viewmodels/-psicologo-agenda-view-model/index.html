PsicologoAgendaViewModel

class PsicologoAgendaViewModel(citasRepository: CitasRepository, authRepository: AuthRepository, userSessionDataStore: UserSessionDataStore)

ViewModel que gestiona la agenda del psicólogo.

Permite visualizar la agenda mensual de citas, gestionar la disponibilidad diaria, crear y cancelar citas, cambiar el estado de las mismas y administrar el horario laboral. También expone la lista de pacientes asignados.

Parameters

citasRepository

Repositorio para operaciones de citas y disponibilidad.

authRepository

Repositorio de autenticación para obtener pacientes asignados.

userSessionDataStore

Almacén local de la sesión del psicólogo autenticado.
