SettingsClienteViewModel

class SettingsClienteViewModel(sessionDataStore: UserSessionDataStore, profileUseCase: ProfileUseCaseGeneral)

ViewModel que gestiona la pantalla de ajustes y edición del perfil del cliente.

Permite cargar los datos del usuario autenticado desde la sesión local y el backend, editar campos como nombre, apellidos, teléfono y dirección, así como persistir cambios o eliminar la cuenta.

Almacén local de la sesión del usuario autenticado.
