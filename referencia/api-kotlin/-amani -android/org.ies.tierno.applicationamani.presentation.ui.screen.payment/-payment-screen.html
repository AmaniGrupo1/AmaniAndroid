PaymentScreen

fun PaymentScreen(citaId: Long, psicologoName: String, fecha: String, monto: String, viewModel: PaymentViewModel, onPaymentSuccess: () -> Unit, onPaymentCanceled: () -> Unit)

Pantalla de pago de una cita mediante la integración con Stripe.

Muestra un resumen de la cita (psicólogo, fecha, importe) y gestiona el flujo de pago seguro a través de Stripe Payment Sheet. Notifica al usuario el resultado del pago (éxito, cancelación o error) y permite reintentar en caso de fallo.

Parameters

citaId

Identificador de la cita a pagar.

psicologoName

Nombre del psicólogo asociado a la cita.

fecha

Fecha de la cita en formato legible.

monto

Importe a pagar.

viewModel

ViewModel que gestiona el flujo de pago.

onPaymentSuccess

Callback invocado cuando el pago se completa con éxito.

onPaymentCanceled

Callback invocado cuando el usuario cancela el pago.
