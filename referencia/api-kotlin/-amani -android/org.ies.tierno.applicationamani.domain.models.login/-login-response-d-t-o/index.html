LoginResponseDTO

data class LoginResponseDTO(val idUsuario: Long, val nombre: String, val rol: String, val token: String, val idPsicologo: Long?, val idPaciente: Long?, val idioma: String, val tema: Boolean)

DTO de respuesta del servidor tras un inicio de sesión o registro exitoso.

Contiene la información mínima necesaria para identificar al usuario autenticado, determinar su rol dentro de la aplicación y almacenar el token de sesión para peticiones autenticadas posteriores.
