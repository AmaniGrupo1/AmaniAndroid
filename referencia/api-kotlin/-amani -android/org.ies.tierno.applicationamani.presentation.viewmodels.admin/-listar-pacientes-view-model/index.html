ListarPacientesViewModel

class ListarPacientesViewModel(val listarPacientesUseCase: TodosLosPacientesUseCase, val darBajaPacienteUseCase: DarBajaPacienteUseCase, userSessionDataStore: UserSessionDataStore)

ViewModel que gestiona el listado de pacientes desde el panel de administración.

Permite listar todos los pacientes, dar de baja o alta a un paciente y reflejar los cambios en la UI de forma reactiva mediante recargas controladas.
