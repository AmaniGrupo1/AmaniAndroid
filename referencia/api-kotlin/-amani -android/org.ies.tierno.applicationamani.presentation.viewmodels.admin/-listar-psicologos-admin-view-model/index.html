ListarPsicologosAdminViewModel

class ListarPsicologosAdminViewModel(val listarPsicologoAdminUseCase: ListarPsicologoAdminUseCase, userSessionDataStore: UserSessionDataStore, val profileUseCase: ProfileUseCaseGeneral)

ViewModel que gestiona el listado de psicólogos desde el panel de administración.

Mantiene dos listas separadas: psicólogos activos y psicólogos dados de baja. Permite editar localmente los datos de un psicólogo y sincronizar los cambios con el backend en segundo plano. También soporta recarga manual de ambas listas.

Parameters

listarPsicologoAdminUseCase

Caso de uso que obtiene la lista de psicólogos activos y de baja.

userSessionDataStore

Almacén local de la sesión del administrador.

profileUseCase

Caso de uso genérico para operaciones de perfil (edición de psicólogo).
