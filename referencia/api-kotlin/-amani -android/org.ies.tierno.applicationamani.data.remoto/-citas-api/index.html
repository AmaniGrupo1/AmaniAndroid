interface CitasApi

Interfaz Retrofit para la gestión de citas, horarios y terapias.

Expone los endpoints que permiten a pacientes y psicólogos crear, cancelar, editar y consultar citas, así como gestionar la disponibilidad horaria del psicólogo y las terapias asociadas.
