DiarioSyncManager

class DiarioSyncManager(context: <Error class: unknown class>, dao: DiarioEmocionalDao, remoteRepository: DiarioRemoteRepository, userSessionDataStore: UserSessionDataStore)

Gestiona la sincronización bidireccional de entradas del diario emocional entre la base de datos local (Room) y el backend remoto (REST).

Responsabilidades:

  1. Encolar trabajos de sincronización inmediata vía WorkManager.

  2. Empujar cambios locales pendientes (CREATE → UPDATE → DELETE) al servidor.

  3. Traer entradas remotas y resolver conflictos por timestamp.
