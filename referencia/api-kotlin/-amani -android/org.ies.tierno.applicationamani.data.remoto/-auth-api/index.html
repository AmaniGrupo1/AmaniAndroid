AuthApi

interface AuthApi

Interfaz Retrofit para los endpoints de autenticación y gestión de usuarios.

Cubre el ciclo completo de autenticación: login, registro de pacientes, psicólogos y administradores, asignación de psicólogos, gestión de bajas/altas y obtención de tokens para Firebase.
