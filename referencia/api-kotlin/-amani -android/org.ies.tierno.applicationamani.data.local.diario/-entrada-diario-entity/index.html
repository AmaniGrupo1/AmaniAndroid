EntradaDiarioEntity

data class EntradaDiarioEntity(val id: Long = 0, val titulo: String, val contenido: String, val emocion: String, val intensidad: Int, val createdAt: Long, val updatedAt: Long, val remoteId: Long? = null, val syncStatus: SyncStatus = SyncStatus.SYNCED, val lastSyncAttempt: Long? = null)

Entidad Room que representa una entrada del diario emocional en la base de datos local.

Almacena el contenido de cada registro junto con metadatos de sincronización que permiten al DiarioSyncManager resolver conflictos entre los datos locales y remotos.
