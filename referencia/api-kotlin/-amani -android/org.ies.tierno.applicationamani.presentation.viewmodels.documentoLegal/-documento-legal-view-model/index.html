DocumentoLegalViewModel

class DocumentoLegalViewModel(useCase: DocumentoLegalUseCase)

ViewModel que gestiona el CRUD de documentos legales desde el panel de administración.

Permite listar, crear, editar, eliminar y consultar documentos legales por tipo mediante DocumentoLegalUseCase. Expone estados de carga, error y el documento seleccionado para visualización o edición.
