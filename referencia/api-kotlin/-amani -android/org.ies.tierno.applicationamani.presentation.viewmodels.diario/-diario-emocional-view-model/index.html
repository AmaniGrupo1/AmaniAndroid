DiarioEmocionalViewModel

class DiarioEmocionalViewModel(repository: DiarioEmocionalRepository)

ViewModel que gestiona el diario emocional del usuario.

Permite crear, editar y eliminar entradas del diario mediante DiarioEmocionalRepository. Expone un SharedFlow de mensajes snackbar para notificar al usuario las operaciones realizadas. Soporta sincronización forzada con el backend y un asistente de creación en 3 pasos.

Parameters

repository

Repositorio local/remoto para operaciones del diario.
