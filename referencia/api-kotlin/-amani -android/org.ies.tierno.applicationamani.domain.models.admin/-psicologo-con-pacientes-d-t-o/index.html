PsicologoConPacientesDTO

data class PsicologoConPacientesDTO(val idPsicologo: Long? = null, val nombrePsicologo: String? = null, val apellidoPsicologo: String? = null, val emailPsicologo: String? = null, val especialidad: String? = null, val licencia: String? = null, val fechaDadoAlta: LocalDateTime? = null, val pacientes: List<PacientesAsignadoDTO>? = null)

DTO que agrupa los datos de un psicólogo junto con la lista de pacientes que tiene asignados.

Se utiliza en el panel de administración para visualizar la relación entre profesionales y pacientes, permitiendo al administrador gestionar las asignaciones y dar de alta o baja a los psicólogos.
