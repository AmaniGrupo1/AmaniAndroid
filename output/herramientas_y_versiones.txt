## Herramientas de Análisis

### 1. APKTool
- **Versión**: 3.0.1
- **Fuente**: https://github.com/iBotPeaches/Apktool/releases/download/v3.0.1/apktool_3.0.1.jar
- **Uso**: Descompilación de APK (res, assets, AndroidManifest.xml)
- **Comando**: `apktool d -f app-debug.apk -o apktool_output/`

### 2. Jadx (Java Decompiler)
- **Versión**: 1.5.5
- **Fuente**: https://github.com/skylot/jadx/releases/download/v1.5.5/jadx-1.5.5.zip
- **Uso**: Descompilación de DEX a Java/Kotlin
- **Comando**: `jadx -d jadx_output/ --show-bad-code app-debug.apk`
- **Nota**: 91 errores durante descompilación (probablemente ofuscación R8)

### 3. AAPT (Android Asset Packaging Tool)
- **Fuente**: android-sdk-tools package
- **Uso**: Metadata extraction, permission listing, manifest inspection
- **Comandos**:
  - `aapt dump badging app-debug.apk`
  - `aapt dump permissions app-debug.apk`

### 4. ApkSigner
- **Fuente**: android-sdk-tools package
- **Uso**: Verificación de firma APK
- **Comando**: `apksigner verify --verbose app-debug.apk`

### 5. Strings Utility
- **Fuente**: binutils package
- **Uso**: Extraction de strings del APK
- **Comandos**:
  - `strings app-debug.apk | grep -E "http|https"`
  - `strings app-debug.apk | grep -E "[A-Za-z0-9+/]{40,}={0,2}"`

### 6. Unzip
- **Fuente**: unzip package
- **Uso**: Extracción de DEX, librerías nativas, recursos
- **Comandos**:
  - `unzip -j app-debug.apk '*.dex' -d dex_output/`
  - `unzip -j app-debug.apk 'lib/*' -d native_libs/`

### 7. File
- **Fuente**: file package
- **Uso**: Determinación de tipo de archivo (native libraries)
- **Comando**: `file native_libs/*.so`

### 8. nm
- **Fuente**: binutils package
- **Uso**: Listing de símbolos en librerías nativas
- **Comando**: `nm -D native_libs/*.so`

### 9. Semgrep
- **Versión**: latest (installado con pip3)
- **Fuente**: https://semgrep.dev/
- **Uso**: Static analysis con reglas Kotlin/Android
- **Comando**: `semgrep --config=p/kotlin jadx_output/ --json`
